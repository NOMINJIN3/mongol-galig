# mongol-galig

Латин галигаар бичсэн Монгол текстийг (`Ugui ee, uur yu hiij boloh uu`) кирилл рүү (`Үгүй ээ, өөр юу хийж болох уу`) хөрвүүлэгч.

## Яагаад хэрэгтэй вэ
Монголчууд утсан дээр, чат дээр латинаар бичих нь их. Ийм текстийг хайлт, NLP загвар, AI чатбот зөв ойлгодоггүй.

## Ашиглах
```bash
python galig.py "Sain baina uu"     # -> Сайн байна уу
python test_galig.py                # нарийвчлал хэмжих
```

## v0.2 хэрхэн ажилладаг вэ
1. `o`, `u` гэх мэт эргэлзээтэй эгшиг бүрийн боломжит хувилбарыг (о/ө, у/ү/ө) үүсгэнэ. Эгшиг зохицох ёсыг баримтлах тул эр, эм эгшиг холилдсон хувилбар үүсэхгүй.
2. Хувилбар бүрийг [MonWN](https://github.com/num-milab/monwn)-ээс авсан 18 мянган үгээр сурсан загвараар үнэлнэ:
   - үг нь үгийн санд байвал их оноо авна
   - байхгүй бол (жишээ нь `хөдөлгөөнжүүлэлтийн` гэх мэт нөхцөлтэй үг) тэмдэгтийн 4-gram магадлалаар үнэлнэ
3. `uu`, `ruu` нөхцөлийг өмнөх үгийн эгшгээр сонгоно (`baina uu` → байна **уу**, `ene uu` → энэ **үү**).

## Өгөгдөл
`data/words.txt` нь Mongolian WordNet (MonWN)-ээс гаргаж авсан үг, давтамжийн жагсаалт юм. Лиценз нь CC BY-SA 4.0.
> Batsuren et al. (2019), *Building The Mongolian WordNet*, GWC.

## Гол бэрхшээл
Нэг латин үсэг хэд хэдэн кирилл үсэг байж болно:
- `u` → у / ү / ө  (`hugjuulelt` = **хө**гжүүлэлт)
- `o` → о / ө
- `y` → ы / ъ / й
- Нэг үгийн эгшиг дараагийн үгийн нөхцөлд нөлөөлнө (`... chiglesen ruu` = **рүү**)
